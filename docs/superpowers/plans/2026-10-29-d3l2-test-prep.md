# D3 L2 test prep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add vocab, pronoun, gustar, reading and mixed modes for Descubre 3 Lección 2, plus a richer motion system.

**Architecture:** A generic exercise engine (`js/core/deck.js`) schedules and checks items supplied by data files (`js/data/l2-*.js`). The UI splits into `js/ui/motion.js` (all GSAP choreography), `js/ui/reading.js` (the reading view) and `js/ui/app.js` (shell, tabs, rail, card flow for both the drill and exercises).

**Tech Stack:** vanilla JS (IIFE on `window.Drill`), GSAP 3.12.5 from cdnjs, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-29-d3l2-test-prep-design.md`

## Global Constraints

- No ES modules; every new script is added to `tests/helpers/load.js` order and `index.html` in the same order.
- `app.css`: token colours only, no italics, transitions only on transform/opacity/visibility, a reduced-motion block.
- Accent-only mistakes are wrong (`result: 'accent'`).
- A missed item returns after `RETRY_AFTER = 3` others.
- vosotros items appear only when `settings.vosotros` is true.

## Review Focus

- Answers with ¿ ¡ . ! ? or doubled spaces must still be accepted (deck.check test).
- Unticking every exercise kind gives an empty deck, not a crash: `next()` returns null (deck test).
- Old saved stores without `mode`/`ex` settings load with defaults (store test).
- Every choice item contains its answer exactly once and has no duplicate options (data test).
- Generated gustar items agree in number: plural thing → plural verb, infinitive → singular (data test).

### Task 1: Exercise engine

**Files:** Create `js/core/deck.js`; Modify `js/core/store.js` (settings `mode`, `ex`); Test `tests/deck.test.js`, `tests/store.test.js`.

**Interfaces:**
- Produces: `D.exercise.norm(s)`, `D.exercise.check(text, answers) -> { result: 'correct'|'accent'|'wrong', marks, expected }`; `D.createDeck({ items: () => Item[], store, rng, now }) -> { next(), answer(prompt, text|index), streak(), best(), count(), accuracy() }`.
- Item: `{ id, mode, kind, skill, prompt, cue?, answers?: string[], options?: string[], correct?: number, why?, big?, gloss? }`. Choice items have `options` + `correct`; typed items have `answers` (first is shown).
- Store settings: `mode` (string, default `'conjugar'`), `ex` (object of mode → list of unticked filter ids, default `{}`).

- [ ] Write tests: check accepts `¿Se las doy?` for `se las doy`; `lo veo` vs `ló veo` → accent; deck returns null on empty items; missed item returns as `retry` after 3 others; choice answer by index; store keeps `mode`/`ex`, drops junk.
- [ ] Run `npm test` → new tests fail.
- [ ] Implement; weighting `[8,5,3,2,1][box]`, avoid the last 4 ids.
- [ ] `npm test` → pass. Commit.
